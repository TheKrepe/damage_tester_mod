# Damage Tester

**Автор:** Star_1mp · **Minecraft:** 26.3 · **Загрузчики:** Fabric и NeoForge

Тренировочный манекен для Minecraft. Поставьте его в мире, и он будет молча стоять, оценивая каждое ваше действие.
Ударьте его, и он забавно покачнётся и покажет, сколько урона вы нанесли.

## Возможности

- **Тестер урона.** Ставится предметом на любой блок и поворачивается к игроку (шаг 22,5°).
- **Не умирает.** Урон измеряется уже после брони, зачарований и эффектов, а здоровье при этом не тратится.
  Показывается настоящий урон, даже если он больше запаса здоровья (удар на 500 покажет 500).
- **Всплывающие цифры урона** над головой. Цвет зависит от типа урона:
  огонь, магия, взрыв, холод, молния, иссушение, шипы, трезубец и другие.
- **Критические удары** показываются крупнее, золотым цветом и со значком ✦.
- **Покачивание.** Манекен откидывается назад и пружинит обратно, сильнее при больших ударах.
- **DPS в строке действий:** последний удар, урон в секунду, общий урон и число ударов за серию.
  Серия сбрасывается после нескольких секунд без ударов.
- **Броня.** Правый клик бронёй, тыквой или головой надевает её на манекен, пустой рукой снимает.
  Удобно проверять, как броня режет урон.
- **Разборка:** удар пустой рукой с зажатым Shift. В режиме выживания манекен выпадает предметом.
- **Раздатчик** может ставить манекены.
- Соломенные частицы при ударе.
- **Редстоун:** манекен на блоке-мишени (или подвешенный под ним) при ударе выдаёт сигнал:
  1 урон = сила 1, 15 и больше = 15. Через секунду мишень гаснет.
- **Скины** (ПКМ предметом, ножницы возвращают обычный вид):
  - сноп сена — соломенный;
  - любые доски, в том числе из других модов — деревянный манекен из этих досок;
  - любой краситель — мешковина нужного цвета;
  - светильник Джека — голова-тыква со светящимся лицом;
  - бирка с именем `jeb_` — переливается радугой, как овца.

## Варианты

| Предмет | Рецепт | Особенности |
|---|---|---|
| Тестер урона | палка, сено, палка / стойка для брони | обычный |
| Маленький тестер урона | сено / палка / деревянная плита (столбиком) | размер ребёнка |
| Подвесной тестер урона | тестер + поводок | вешается под блок (ПКМ по нижней грани), раскачивается как груша |
| Движущийся тестер урона | тестер + вагонетка | ездит по кругу; Shift + ПКМ пустой рукой: круг → вперёд-назад → стоп |
| Счётчик урона (блок) | доски, стеклянная панель, мишень, редстоун | показывает удар, DPS, всего, число ударов и максимум ближайшего манекена (до 8 блоков) |

## Рецепт

```
 S H S      S = палка
   A        H = блок сена
            A = стойка для брони
```

## Настройки

Файл `config/damage_tester.json` создаётся при первом запуске:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `showDamageNumbers` | `true` | Всплывающие цифры урона (клиент) |
| `damageInHearts` | `false` | Показывать урон в сердечках (1 ❤ = 2 урона) |
| `wobbleIntensity` | `1.0` | Сила покачивания, `0` выключает анимацию (клиент) |
| `showDpsMessage` | `true` | Статистика в строке действий (сервер) |
| `combatResetSeconds` | `5` | Через сколько секунд без ударов сбрасывается серия (сервер) |
| `hayParticles` | `true` | Частицы соломы при ударе (сервер) |

## Сборка

Нужен JDK 25. Проект собран по шаблону MultiLoader:
код и ресурсы лежат в `common`, а в `fabric` и `neoforge` только подключение к загрузчику.

```bash
./gradlew build
```

Готовые файлы:
- `fabric/build/libs/damage_tester-fabric-26.3-<версия>.jar` (нужен Fabric API)
- `neoforge/build/libs/damage_tester-neoforge-26.3-<версия>.jar`

Запуск в разработке: `./gradlew :fabric:runClient` или `./gradlew :neoforge:runClient`.

### Автоматические проверки (GitHub Actions)

- **Build** собирает оба jar-файла и прикладывает их к запуску как артефакт.
- **Runtime tests:**
  - запуск выделенного сервера Fabric и NeoForge до строки `Done`;
  - запуск клиента NeoForge до главного меню;
  - клиентский игровой тест Fabric (`./gradlew :fabric:runClientGameTest`). Он ставит манекены,
    бьёт их разными типами урона, проверяет крит, бессмертие и разборку и делает скриншоты.
